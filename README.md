# Wordle

A five-letter word-guessing game designed for older adults, with voice play and read-aloud.

## Playing the game

**Scan the QR code on the flyer** with your phone or tablet camera and tap the link that
appears, or type this address into your web browser:

**https://mickeynotmouse.github.io/Wordle/**

There is nothing to install and no account to make. It works on phones, tablets and computers,
but you need an internet connection.

**Which browser:** Chrome, Edge or Safari work best. Firefox can show and read out the game,
but it can't hear you speak, so if you use Firefox you would only be able to use the on-screen keyboard.

### Microphone and sound

- **Allowing the microphone:** the first time you tap the microphone button, your browser
  asks if the game may use your microphone. Tap **Allow**. The game only listens while the
  microphone button is on, and you can always type your guesses with the on-screen keyboard instead.
- **If you tapped "Block" by mistake:**
  - *Computer (Chrome/Edge):* click the icon to the left of the web address, set
    **Microphone** to **Allow**, then reload the page.
  - *iPhone/iPad:* tap **aA** in the address bar → **Website Settings** → **Microphone** →
    **Allow**. If the game still can't hear you, go to **Settings → Safari → Microphone**.
  - *Android:* tap the icon left of the web address → **Permissions** → turn on **Microphone**.
- **Hearing the game:** turn the volume up and, on an iPhone, make sure the silent switch is
  off. On phones, tap anywhere on the game once after it opens – this lets it start speaking.
- **Quiet is best:** speak clearly, close to the device, with little background noise.
- **First guess a little slow?** The voice assistant may take a few seconds to wake up the
  first time. If it can't be reached, you'll see "Basic voice mode" under the microphone –
  the game still works, it just understands fewer ways of saying things.

On a computer you can press the **space bar** instead of clicking the microphone.
